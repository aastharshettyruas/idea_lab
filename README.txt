MEALMATES — PHASE ONE WEBSITE

Included
- Responsive MealMates website for desktop and mobile browsers.
- Overview dashboard, Explore Groups, Create a Group, My Orders, My Profile.
- Demo group cards, target progress, menu preview and interactive cart.
- Demo cart lock, participant dropout and out-of-stock simulations.
- Sample profile, reliability score and savings information.

How to run
1. Extract the ZIP file.
2. Open index.html in a modern browser (Chrome, Edge, Firefox or Safari).
3. No installation or server is required for this frontend prototype.

Important Phase One scope
This is a front-end prototype. It uses sample data and browser-side JavaScript.
It does not yet include user authentication, persistent cloud storage, real GPS,
live multi-user carts, restaurant API integrations, payment processing, real
restaurant checkout, or delivery tracking. Those are later development phases.
The "Indiranagar, Bengaluru" location and sample profile are demonstration data.
No real order or payment is made by this website.

Product direction
MealMates is planned as a standalone hybrid platform: it owns the group-ordering
experience and can connect to restaurants or authorised delivery-platform
integrations when access and partnerships are available.
